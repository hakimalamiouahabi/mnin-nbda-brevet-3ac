# MNIN NBDA — Utiliser mes 700 experts directement dans ChatGPT

## C'est prêt comme méthode de travail, sans serveur et sans API IA payante

Les **700 profils d'origine** restent dans GitHub et peuvent guider mes réponses **pendant notre conversation**. Ce sont **5 DSI, 30 Senior Managers, 60 Managers, 60 Team Leaders et 545 experts**, sans nouveau poste.

Tu n'as pas besoin d'installer le plugin, d'ouvrir Codex ou d'utiliser Work pour **me demander le travail**. Le dépôt sert de carnet des rôles et des responsabilités.

### Comment donner une mission ?

Écris, comme tu parles :

> DSI, mobilise les experts adaptés et audite la page d'accueil MNIN NBDA.

Ou :

> DSI, fais examiner la base Cloudflare MNIN pour repérer ce qu'on peut optimiser sans rien supprimer.

Ou :

> DSI, passe la maquette en revue comme une équipe design, WordPress, performance et qualité.

Tu peux également demander : **« Qui as-tu mobilisé pour cette mission ? »** Je donnerai les spécialités et les identifiants existants réellement consultés. Pas de profils inventés.

### Ce qui se passe réellement

1. Je comprends ta mission.
2. Je sélectionne, parmi les **700 profils enregistrés**, le DSI responsable et les spécialistes concernés.
3. J'examine le problème en tenant compte de leurs savoir-faire et de leurs contrôles métier, au sein **d'une seule conversation ChatGPT**.
4. J'utilise, si nécessaire, les connecteurs autorisés pour interroger GitHub, WordPress ou Cloudflare et produire un travail vérifiable.
5. Je te rends **une réponse claire**, une maquette ou un rapport, sans t'encombrer d'une organisation interne inutile.

Cela **ne signifie pas que 700 modèles indépendants exécutent 700 raisonnements simultanés**. Un seul ChatGPT exploite les fiches de rôles. Pas de travail permanent en arrière-plan, pas de nouvelles ressources à acheter pour le simple échange.

### Règle officielle de sélection

Consigne opérationnelle :
[`mnin-bridge/skills/chat-only-700/SKILL.md`](../skills/chat-only-700/SKILL.md).

Registre complet inchangé :
[`mnin-bridge/agentgrid/profiles-700.json`](../agentgrid/profiles-700.json).

La sélection se fait selon la mission, en général avec **3 à 12 expertises** parmi les 545, plutôt que de faire intervenir artificiellement tout le monde. Les cinq directions coordonnent les thèmes design, WordPress/logiciel, pédagogie, data/IA et sécurité/exploitation.

### Limites simples

- ChatGPT **n'est pas** 700 intelligences autonomes distinctes ; il utilise les 700 profils comme méthodologie spécialisée.
- Les accès GitHub, Cloudflare et WordPress ne sont utilisés que selon les autorisations réelles de la conversation.
- Les changements sensibles (dépenses, suppressions, production, données d'élèves) restent sous contrôle.
- Le contenu de GitHub ne charge pas automatiquement cette consigne dans toutes les nouvelles conversations : dans un nouveau chat, tu peux demander **« Charge MNIN NBDA / protocole Chat Only 700 depuis GitHub puis travaille sur [mission] »**.
- Pour les tâches indépendantes, tu n'as pas besoin d'un serveur dédié ; en revanche, un test navigateur ou un calcul réel utilise les outils/serveurs déjà disponibles lorsqu'ils sont nécessaires.

### Notre point de départ

La Home MNIN NBDA approuvée est la référence. Les futures missions peuvent mobiliser les spécialistes du design, SVG/8K, frontend, responsive, performance et QA.
